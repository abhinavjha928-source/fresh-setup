# ⚡ Fresh Setup 

> **Everything You Need After A Fresh Install.**

![Status](https://img.shields.io/badge/Status-Active-success.svg) ![Tech Stack](https://img.shields.io/badge/Tech-HTML%20%7C%20CSS%20%7C%20JS-yellow.svg) ![License](https://img.shields.io/badge/License-MIT-blue.svg)

**Fresh Setup** is a curated, zero-bloatware software directory designed to make setting up a new PC effortless. It provides quick access to over 100 essential applications, entirely built with pure Vanilla Web Technologies. 

**Crucially, every single link points to the official source. No affiliate links. No tracking. No ads.**

## ✨ Features

- **🎯 100+ Curated Apps**: Hand-picked software across 11 distinct categories.
- **🔍 Instant Search**: Lightning-fast, real-time filtering using `Ctrl+K`.
- **🎨 Matte Minimalist Design**: A beautiful, dark-themed UI with subtle mouse-glow effects and smooth animations.
- **📱 Fully Responsive**: Flawless experience on desktop, tablet, and mobile.
- **🔒 100% Safe Links**: Strict adherence to linking only to official, secure domains.

## 🗂️ Categories Included

- 🌐 **Browsers** (Privacy-first, gaming, and mainstream)
- 🛠️ **Developer** (IDEs, runtimes, containers, API clients)
- 🎮 **Gaming** (Launchers, utilities, remote play)
- 🎨 **Creator** (Video editing, 3D, digital painting)
- 🤖 **AI Tools** (LLMs, local models, image generation)
- 📋 **Productivity** (Workspaces, communication, managers)
- 📚 **Student** (Flashcards, citations, learning platforms)
- 🔒 **Privacy** (VPNs, encryption, password managers)
- ⚡ **Power User** (Advanced system utilities, automation)
- 🎵 **Media** (Players, servers, home theatre)
- 🖥️ **System** (Hardware monitoring, uninstallers, disk analyzers)
